# Roadmap

killpass is deliberately small. The core is frozen; growth is governed by
[the expansion doctrine](https://github.com/srinu16it/killpass/blob/main/ARCHITECTURE.md)
(*reach, never scope*).

**Shipped (0.4.x)**, Skeptic core, the mechanical grounding gate, quote
discipline (dump/echo/length), declared-source validation, strict-all
grounding, truncation guard, operational/content split, input bounds,
provenance/audit (evidence offsets, source hashes), a frozen verdict schema
(v3), dual-skeptic mode, source loaders (docx/url; PDF extra), zero
dependencies.

**Possible later**, only changes that respect the doctrine: honest
long-document chunking guidance, more neutral API examples. Framework
adapters and CLIs belong in community repos under their own names.

Suggest a trap: open an issue with a real, dated example of a claim that
fooled an AI. Real failures only.
