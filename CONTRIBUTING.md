# Contributing

- Plain language everywhere: README and docs must be readable by
  non-engineers. If a sentence needs jargon, gloss it.
- The skeptic's contract is load-bearing: default to INSUFFICIENT, never loosen
  the grounding rule, never reward confirmation.
- Every new trap needs a test built from a real, documented failure case.
- Run `pytest` before any PR. Zero runtime dependencies is a feature.
